# Suggested Experiments

1. Compare Random Forest with Logistic Regression and Gradient Boosting.
2. Compare Isolation Forest with One-Class SVM and Local Outlier Factor.
3. Test class-weighting versus resampling for imbalanced threat classes.
4. Vary anomaly contamination from 5% to 20%.
5. Add 5%, 10%, and 20% feature noise and compare macro-F1.
6. Compare random train/test split with time-based validation.
7. Remove one feature group at a time to measure robustness.
8. Analyze device-level false positives and investigate the underlying flows.
